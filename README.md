Hello here is several **USEFUL add-ons** that I made intro animation creation process. This addons is helpful for me, and I hope it's been useful for you too. 

1. **Clear Channels** addon – is delete unused Graph Editor channels or useless keyframes. Use: move your mouse to graph editor and press SHIFT+X for call menu.

2. **Graph Editor Handle Tools** – allow you edit handles by rotate, copy and align by usind Graph Editor side menu. Also you can use shortcut "E" for special rotate handles.

3. **Graph Editor Pressets Tools** – addon for save presset of selected keyframes per one channel. You should select two keyframes and after you use saved preset intro side menu new keyframes will be adapted to value of two keyframes that you selected before. For fast selection, I added a pie menu with all saved pressets. 

4. **Keyframe Stretch** – by using "D" shortcut you can stretch keyframes to the left or rigt direction. If your cursor closer to right side of selected keyframes after you pressed "D" stretch was scale up or down used left side as ancor and run scale command what alloy you compress or stretch keyframes horizontally.

5. **Fast Sace As** – was add new fast save menu and save notification function. Shortcut: ctrl+shift+s run two buttons menu. "Save" button save project with diferent number (project_zero_1 => project_zero_2). Save Reminder timer function can setup in addon settings preferences window. Also have "Force Auto save" with same  function as "save" button do.
